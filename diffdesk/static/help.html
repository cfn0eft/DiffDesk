はじめに — 5分で照合

DiffDeskは「ヘッダーが違う2つの表データ」を突き合わせるローカルツールです。データは外部に送信されません。

  1. 読み込み — 2つのファイル(CSV / TSV / Excel)を画面にドロップ。最初の2つが自動で 基準(A)・比較(B) になります
  2. おまかせで差分実行 ▶ を押す — 列の対応とキーを自動推定してすぐ照合します
  3. 照合結果を見る — 上部の判定(OK / 要確認)と、色付きの差分表(赤=Aのみ / 緑=Bのみ / 黄=値の相違)を確認
  4. 行をクリックすると全項目の照合詳細。問題ない差異は「既知にする」で容認
  5. 必要なレポートを出力(照合レポート / 検証パックzip / Data Loader用CSV)
自動推定が合わないときだけ「2. 紐づけ」タブで列の対応とキーを手で直します。設定はプロファイルに保存すれば翌月から読み込むだけです。

1. 読み込みタブ

ファイルの読み込みとA/Bの割当

  • ファイルは何個でも読み込めます。一覧のラジオボタンで 基準(A) と 比較(B) を選びます
  • A=正とするデータ(移行元・マスタ)、B=確認したいデータ(Salesforceエクスポート等)です
  • 「A ⇔ B を入れ替え」でワンクリック交換できます

文字化け・読み込み設定

  • エンコーディング(UTF-8 / CP932等)は自動判定されます。化けたら「読込設定」からエンコーディングを選び「再読込」— プレビューが直れば正解です
  • Excelはシートとヘッダー行の位置(タイトル行が上にある場合など)を指定できます
  • 先頭ゼロ(0001等)は壊れません。全セルを文字列として扱います

事前診断(プリフライト)

A/Bを選ぶと自動で診断が表示されます: 行数差・キー候補(ユニークな共通列)・重複行・全行空の列など。⚠が出たら差分実行前に確認すると手戻りを防げます。

セッション保存/復元

「セッション保存/復元」パネルで、読み込んだファイルの中身・A/B割当・紐づけ設定をまるごと保存できます。翌日は「復元」を押すだけで差分実行まで自動で戻ります。

2. 紐づけタブ

列マッピング

  • 「自動対応付け」— 列名の一致(全半角ゆれ含む)・ユーザー辞書・値の中身から対応を推定します
  • 手動で直すときは各行のプルダウンで A列↔B列 を選択。「＋ペアを追加」で増やせます
  • キー☑ = レコード同士を結びつける列(社員番号・検体番号など)。複数列の複合キーも可
  • 「対応を辞書に学習」— 今の対応を記憶させ、次回の自動対応付けで最優先されます

キー方式(キーになる列がないとき)

方式動作使いどころ
キー列で結合(既定)キー☑の列で照合IDがある通常の照合
行番号で比較上から順に1行ずつ突き合わせ並び順が同じ出力同士
行の内容で比較全列一致した行同士を対応付け(順不同)「同じ行が両方にあるか」だけ確認

比較オプション(正規化)

  • 前後の空白 / 全角半角(NFKC)/ 大文字小文字 / 数値表記(1551 = 1551.0)を同一視できます。既定は空白・全半角・数値がON
  • 正規化は比較にだけ使われ、表示と出力は常に元の値のままです

行フィルタ・プロファイル

  • 行フィルタ: 比較前にA/Bそれぞれを条件で絞り込み(例: 部署=営業部のみ)
  • プロファイル: マッピング+オプション+フィルタ一式を名前を付けて保存/読込。JSONファイルとしての書出/読込も可

3. 照合タブ

3つのサブタブに分かれています: 照合結果紐づけ・既知の管理履歴・証跡

照合判定

  • 最上部に OK / 要確認 の判定と進捗バー。「Aの全レコードがBに正しく登録されているか」を判定します
  • Bにしかないレコードが正常な運用なら「SFに元からあるレコード(Bのみ)を許容する」をON

前回との比較(定例照合向け)

  • 同じファイル名の組で照合すると、前回実行時との差が表示されます: 🆕新規差異(前回OK→今回NG: 要調査)/ 継続 / ✔解消
  • 「新規差異」チップをクリックすると、今月新たに発生した問題行だけに絞り込めます
  • スナップショットは案件ごと・ファイル名の組ごとに自動保存されます(操作不要)

差異の内訳(自動分類)

  • 変更セルの「なぜ違うか」を自動で仕分けします: 空白 / 全角半角 / 大小文字 / 数値表記 / 日付形式 / ゼロ埋め / 複合 / 真の相違
  • チップをクリックするとその原因の行だけに絞り込み。「真の相違」だけ見れば本当に確認すべき差異に集中できます
  • 表記ゆれ系の分類は「✓一括既知」でまとめて容認できます(値ルールとして登録。↩元に戻す1回で取り消し可)

検索・絞り込み

  • 差分表の検索ボックス: キーやセルの値の部分一致で行を絞り込み(例: 社員番号や氏名の一部)
  • 「差異の多い項目」の列名チップ: クリックでその列に差異がある行だけ表示(再クリックで解除)

差分表の見方

  • 統合表示: 1レコード1行。変更セルは「A側の値 → B側の値」。クリックでマージ採用側を選べます
  • 左右分割表示: エディタ風に左=A・右=B。同じ高さの行が対応レコード、スクロール連動
  • 表示フィルタ: 全て / Aのみ / Bのみ / 未対応 / 変更 / 一致(件数付き)
  • 行クリック=照合詳細(全項目の✔✖)。n / p で次/前の要確認行へジャンプ
  • 「⛶ 全画面」で広く表示、「👀 見比べ」は照合なしの目視確認用別ウィンドウ

手動紐づけ・候補提案

●ドラッグで紐づけ(キーが違うレコード同士をペアに)

  1. 左右分割表示にして、表示フィルタを「未対応」にする → 紐づけモード(左=Aのみ・右=Bのみを詰めて表示、左右独立スクロール)
  2. 行端の ● をドラッグして反対側の行に落とす
  3. 一致率プレビュー付きの確認画面で「紐づけ」を押す(⇔印が付きます)
紐づけはキーの組で保存されるので、同じファイルで差分を再実行しても自動で再適用されます。解除は詳細画面か「手動紐づけの管理」から。

候補の自動提案と一括承認

  • 「候補を自動提案」— 値の類似度から「同じレコードらしい組」を提案(しきい値変更可)
  • 「この一致率以上を一括承認」— しきい値(100%のみ〜60%以上)を選んでまとめて登録。実行前に件数の確認が出ます

既知差分(「確認済み・問題なし」の容認)

照合詳細画面(行クリック)から3種類の登録ができます:

種類ボタン効果
セル差分既知にする(この行のみ)この行のこの項目の差異だけ容認
値ルール(全行)全行で既知…同じ値の組(例: 男→Male)を全行まとめて容認。件数確認あり
欠落行この欠落を既知にするAのみ/Bのみのレコードの欠落を容認
  • 登録した差異は以後の照合で問題に数えず、判定・レポートでは「既知」として区別されます
  • 一覧・削除は「紐づけ・既知の管理」サブタブ。誤登録は↩ 元に戻すでも取り消せます

案件・セッション・元に戻す

案件(画面上部)

  • 既知差分・照合履歴・手動紐づけ・ユーザー辞書・セッション・監査ログは案件ごとに保存されます
  • 「＋新規」で案件を作成。切り替えると画面のデータもその案件のものに変わります
  • 今までのデータは「既定」案件にそのまま残っています

↩ 元に戻す(統一アンドゥ)

  • 既知差分・手動紐づけ・ユーザー辞書の登録/削除/全削除を直近30操作までさかのぼって取り消せます
  • ボタンにマウスを乗せると「次に取り消される操作」が表示されます

セッション保存/復元

  • 読み込みタブのパネルから。ファイルの中身ごと保存されるので、元ファイルが手元になくても復元できます
  • 同名で保存すると上書き。案件を切り替えるとその案件のセッション一覧になります

履歴・証跡サブタブ

  • 照合履歴: 実行ごとの一致率・件数の推移
  • 監査ログ: いつ・何をしたかの操作記録(照合実行・登録・出力など)。CSV出力可

Salesforce連携(Data Loader用)

照合結果サブタブの出力欄 →「Salesforce連携」。DiffDeskはSalesforce APIに接続しません(CSV生成のみ)。

  • アップサートCSV: Aのみ(insert)+変更(update)行をAの値で出力。外部ID列と文字コード(既定: UTF-8 BOM付き)を選択。ヘッダーは「SF項目名」欄で変換できます
  • 復元用CSV: 変更行の「投入前のSF値」をupdate用に保存。投入前に必ず出力しておくと、誤投入時にこのCSVで元に戻せます
  • 削除用CSV: Bのみ行のId。Data Loaderの削除は取り消せないため、内容を必ず確認してから
  • .sdlマッピング: Data Loader側のフィールド対応ファイル。読み込めば手作業のマッピング不要

投入後の確認(ツールタブ)

  • エラーファイル分析: Data Loaderの error.csv を読み込むと失敗理由を日本語で集計し、対処ヒントと再投入用CSVを生成
  • success.csv から新規作成レコードの取り消し用delete CSVも作れます

多対多検証(中間オブジェクト)

「症例 × 検査項目」のような中間(ジャンクション)オブジェクトの投入検証を行います。

  1. 投入元データと、Salesforceからエクスポートした中間オブジェクトを読み込む
  2. 複合キーの組み立てルールを設定(例: {A}-{B})。「テンプレートを自動推定」も使えます
  3. 照合すると、一致 / 欠落(投入漏れ)/ 想定外 を分類し、孤児レコードの原因(親Aなし・親Bなし・原因不明)を分析します
  4. 関係ビューで「どの親にどのレコードがぶら下がっているか」を目視確認できます

移行定義JSON(fields / valueMap / composite等)を読み込むと、投入時の変換を再現した照合ができます(紐づけタブの「JSONファイル読込」)。

編集・整形 / ツール

編集・整形タブ

  • グリッドでセル編集(Enterで下へ移動)・行列の追加削除・ソート。「元に戻す」対応
  • 検索・置換(正規表現可)、一括クレンジング(空白除去・全半角・日付統一・数値表記ほか)
  • 表記ゆれ検出→一括統一、検証(重複・必須・形式・許可値・範囲)、列の分割/付加、匿名化 など
  • 編集後は「サーバーに保存」してから、CSV / Excel でダウンロード

ツールタブ

  • 参照整合性チェック: 「このファイルのこの列の値は、マスタ側の列に存在するか」を検証。Data Loaderの「参照先が見つかりません」を投入前に予防(不一致行のCSV出力可)
  • ファイル結合(縦)/ 完全重複行の削除 / 文字コード一括変換(対象は読み込みタブの一覧でチェック)
  • Data Loaderエラーファイル分析 / ファイル健康診断(列プロファイル+「いつもと違う」検知)

Web版AI連携(コピペ方式)

紐づけの判断が難しいとき、Web版のAI(Gemini等)に判断させることができます。DiffDesk自体はAIに一切接続しません — プロンプトのコピーと回答の貼り付けだけです。

  1. 「紐づけ・既知の管理」サブタブ →「Web版AIに判断させる」→「AI用プロンプトをコピー」
  2. ブラウザでAIに貼り付けて実行
  3. AIの回答(JSONを含むテキスト)をそのまま貼り戻して「回答を取り込み」
  4. 候補として表示されるので、内容を確認して承認(勝手に登録はされません)

差異の仕分けをAIに依頼

  1. 「仕分けプロンプトをコピー」— 変更セルの値の組(最大200種)を、known(容認できる差異)/ real(真の相違)の判定依頼として生成
  2. AIの回答を貼り戻すと、known判定の候補が一覧表示されます
  3. 内容を確認し、チェックしたものだけ「既知に登録」(値ルール・アンドゥ1回で取消可)

個人情報ガード

プロンプトのコピー前に、氏名・メールアドレス・電話番号など個人情報らしき列を自動検出して警告します。所属のルールで問題ない場合のみ続行してください(検出は補助であり完全ではありません)。

プロンプトには行データがそのまま含まれます。個人情報・機密情報の取り扱いルールに従って使用してください。

よくある質問

プレビューが文字化けする

自動判定が外れています。読み込みタブの「読込設定」からエンコーディング(CP932 / UTF-8等)を選び直して「再読込」。プレビューが直れば正しい判定です。

ポート8765が使用中と言われる / 起動してもすぐ終了する

別のDiffDesk(または他のアプリ)がポートを使っています。v0.20.0以降は自動で空きポート(8766〜)に切り替えて起動し、メッセージを表示します。python -m diffdesk --port 8770 のように番号指定もできます。

1551 と 1551.0 が差異になる

既定では同一視します。差異になる場合はヘッダーのバージョンが古い可能性(下記)か、比較オプションの「数値の表記を同一視」がOFFです。逆に厳密に区別したいときはOFFにしてください。

キーになる列がない

紐づけタブの「紐づけキー」を「行番号で比較」(並び順が同じ場合)か「行の内容で比較」に切り替えます。

1つのセルだけ既知にしたいのに全部が既知になった

「既知にする(この行のみ)」= 1セルだけ、「全行で既知…」= 同じ値の組を全行まとめて、です。間違えたら ↩ 元に戻す で取り消せます。

更新したのに画面が変わらない

ヘッダー右上のバージョン表示を確認してください。古いままなら、アプリを再起動(ターミナルでCtrl+C→再度 diffdesk)し、ブラウザを再読み込みします。

CP932で保存するとエラーになる

CP932で表せない文字(例: 𩸽)が含まれています。エラーに行・列・文字が表示されるので、修正するか UTF-8(BOM付き)で保存してください。

キー重複の警告が出た

同じキー値の行は正しく突き合わせできないため照合から除外されています。編集・整形タブの検証で該当行を特定できます。

データはどこに保存される?

ホームフォルダの .diffdesk 配下です(案件別データは projects/、プロファイルは profiles/)。外部への送信はありません。

アップデートするには

python -m pip install --upgrade "diffdesk @ git+https://github.com/cfn0eft/DiffDesk.git" を実行して再起動。新しい版が出るとヘッダーに ⬆ バッジが表示されます。
